# Minecarts Updated

Connect two minecarts by using an iron chain on each cart in turn. They must be within 3 blocks and on the same connected rail line; the chain is consumed when the link is made. Use shears on a linked cart to uncouple all of its links; one iron chain is dropped per link and the shears lose durability.

Linked carts follow the recorded path of the train head at a fixed spacing. Vanilla minecart types and rail blocks are supported.
